This project captures the data-analysis side of the submitted cybersecurity work.

## Evidence-backed work

The archive supports:

- security data analysis in Excel
- structured review of assessment results
- tabulation of findings and observations
- comparison of events or results across lab exercises
- reporting-style summaries for technical evidence

I am not claiming full-scale SIEM analytics engineering or advanced statistical modelling beyond what the coursework evidence supports.
