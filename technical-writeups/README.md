# Technical Write-ups

This folder is for concise portfolio write-ups that explain what was done, what the evidence shows, and what the mitigations were.

## Use this folder for

- risk mitigation summaries
- lab methodology notes
- evidence explanations
- defensive recommendations
- short technical reflections

## Good writing standard

Each write-up should separate three things clearly:

- what was actually performed
- what was simulated or lab-only
- what was recommended rather than implemented

## Suggested write-up topics

- Wazuh SIEM deployment summary
- Network enumeration and traffic analysis summary
- Linux hardening and firewall controls summary
- Script-by-script explanation of the automation work
- Incident-response-style investigation summary

## Scope note

Do not include formative assessments themselves in this folder. Keep the material portfolio-facing and evidence-based.
