# Network Security Assessment

I carried out network discovery and service review against authorised lab hosts, including intentionally vulnerable systems. The work combined Nmap results with packet and traffic inspection.

## What I worked on

- Nmap discovery, port analysis, and version detection
- Wireshark and tshark traffic inspection
- WireGuard connectivity in the lab environment
- review of FTP, SSH, HTTP, SMB, MySQL, and other exposed services
- vulnerability assessment and practical remediation recommendations
